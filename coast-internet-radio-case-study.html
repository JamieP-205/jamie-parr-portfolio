Case study

Coast Internet Radio

A live redevelopment for a small Newry radio station. I worked directly with the owner on what listeners needed, then built and maintained the public site and the technical pieces behind it.

HTML, CSS, JavaScript, Netlify and Cloudflare Workers

What I was solving

The station's audio stream and now-playing source are served over HTTP while the website is HTTPS. Browsers block that mixed content, so the player could not simply point at the original sources.

I put two Cloudflare Workers in front of them: one for the audio stream and one for metadata. The website can then use HTTPS for both.

What I built

The public site has the live player, now playing, coming up, recent tracks, show information, listening options and display preferences. The player also uses the Media Session API so phone media controls behave more like a normal radio app.

I also built an admin area so the station owner can change day-to-day content, review feedback, view analytics and inspect play history without editing the site files.

Admin and security

The admin functions run on Netlify. Sessions are signed and stored in an HttpOnly, Secure, SameSite=Strict cookie. Passwords are checked using scrypt hashes, writes require a CSRF token and same-origin check, and six failed logins trigger a fifteen-minute block for that address.

Site content, rate-limit data and other server-side records use Netlify Blobs. The analytics are first party and the implementation does not store raw IP addresses.

One useful failure

While checking the live site I found that an inline script had changed without the matching Content Security Policy hash being updated. Saved display preferences could therefore be blocked before the page rendered.

I fixed the hash and added a build check that recalculates the inline-script hashes, so the same mismatch now fails validation instead of quietly reaching the live site.

What I would improve next

The main gap is end-to-end coverage for the admin area. The repository has focused automated checks, but some admin release checks still depend on me clicking through the interface manually.
